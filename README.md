LogistiCR - Base de datos SQL

Descripción

LogistiCR es un proyecto académico desarrollado como parte de mi formación en Informática. Consiste en el diseño y desarrollo de una base de datos para un sistema de gestión logística.

El proyecto permite aplicar conceptos fundamentales de bases de datos relacionales mediante la creación de tablas, definición de relaciones y ejecución de consultas SQL.

Objetivos

Diseñar una estructura de base de datos relacional.

Definir relaciones entre tablas mediante llaves primarias y foráneas.

Insertar y administrar información.

Realizar consultas para obtener información relevante de la base de datos.

Aplicar funciones de agregación para generar resultados y reportes.

Tecnologías utilizadas

MySQL: sistema de gestión de bases de datos.

SQL: lenguaje utilizado para la creación, manipulación y consulta de datos.

GitHub: almacenamiento y documentación del proyecto.

Conocimientos aplicados

Durante el desarrollo del proyecto se trabajaron conceptos como:

Creación de tablas e inserción de registros.

Relaciones entre tablas y llaves foráneas.

Consultas utilizando SELECT, WHERE y LIKE.

Unión de tablas mediante INNER JOIN.

Funciones de agregación como COUNT(), SUM() y AVG().

Agrupación de resultados mediante GROUP BY y filtros con HAVING.

Actualización de registros mediante UPDATE.


Proyecto académico desarrollado con fines educativos y de práctica en bases de datos relacionales.
